How to use these reports

Suggested workflow
1. Filter the Dashboard by month for the period-end snapshot.
2. Export CSV files and consolidate in Excel for COA-style reports.
3. Print Payment Slips & Receipts from Documents for each payee.
4. Back up data monthly via Settings → Export Backup (JSON).

Period Lock (Monthly Close)

Lock a month after reporting — records in that month become read-only (no edits, no deletes) until unlocked.

Users & PINs — Access Protection

Every user signs in with their own PIN (stored only as a one-way hash). The Audit Trail stamps each entry with the signed-in user.
To switch identity, use Logout in the top bar.

Data Management
